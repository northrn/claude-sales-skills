# Account Research Skill

Deep dive research on a single company before outreach or sales conversations.

## Quick Start

```bash
cp account-research.md ~/.claude/skills/
```

## Trigger Phrases

- "research [company]"
- "tell me about [company]"
- "deep dive on [company]"
- "account research for [company]"

## Output

Generates `[company]-research.md` with:
- Company snapshot (size, funding, location)
- Key people with LinkedIn profiles
- Tech stack
- Recent news and triggers
- Likely pain points
- Personalized outreach angles
- Discovery questions

## Example

```
> research Stripe

Generating research dossier for Stripe...

✓ Company overview
✓ Found 15 key executives
✓ Tech stack identified
✓ 8 recent news items
✓ 4 outreach angles generated

File created: ~/Documents/stripe-research.md
```
