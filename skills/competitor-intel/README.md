# Competitor Intel Skill

Map competitive landscape and generate sales battlecards.

## Quick Start

```bash
cp competitor-intel.md ~/.claude/skills/
```

## Trigger Phrases

- "analyze competitors for [product]"
- "competitive landscape for [market]"
- "battlecard for [competitor]"
- "who competes with [company]"

## Output

Generates `competitive-intel-[date].md` with:
- Competitive landscape map (direct, indirect, emerging)
- Feature comparison matrix
- Pricing comparison
- Positioning analysis
- Battlecards for each competitor with:
  - Their strengths (acknowledge)
  - Their weaknesses (exploit)
  - Landmine questions
  - Objection responses
  - Proof points

## Example

## Refresh Cadence

- Full refresh: Quarterly
- After losses: Immediate
- Pricing check: Monthly
