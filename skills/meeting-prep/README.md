# Meeting Prep Skill

Generate a pre-call brief to walk into any sales conversation prepared.

## Quick Start

```bash
cp meeting-prep.md ~/.claude/skills/
```

## Trigger Phrases

- "prep me for call with [company]"
- "meeting prep for [company]"
- "prepare for meeting with [person]"
- "call prep for [company]"

## Output

Generates `[company]-meeting-prep.md` with:
- 30-second company context
- Attendee profiles with LinkedIn and rapport hooks
- Recent news to reference
- Tailored discovery questions
- Likely objections with responses
- Key talking points
- Conversation starters

## Example

```
> prep me for call with Notion, meeting Sarah Chen

Generating meeting prep...

✓ Company context
✓ Sarah Chen profile researched
✓ Found recent product launch to reference
✓ 6 discovery questions generated
✓ 3 likely objections with responses

File created: ~/Documents/notion-meeting-prep.md
```

## Best Practice

Review the prep 5-10 minutes before your call. Focus on:
1. Attendee background (find rapport hook)
2. Recent news (reference in first 2 minutes)
3. Top 3 discovery questions
